# v0.2.7 — 面板不再替你做取舍

## 轮询：默认 60 秒

面板是共享 Markdown 文件的观察窗，轮询是为了看到别的进程（WorkBuddy、另一个会话、编辑器）写进来的内容。但 3 秒只是默认值，不是需求：面板没打开时组件根本不挂载，定时器本来就不存在；打开后 60 秒一次也足够看到变化。想更快仍可在设置里调回去。

## 项目列表：全部展示

「最多展示项目」是一个防御性配置，代价是第 51 个项目从左栏消失，连搜索也搜不到。目录统计本来就是全量的，去掉切片不会让后端更忙；几百个工作区的真实成本是每次轮询几十毫秒、几百 KiB，60 秒一次可以忽略。所以这个配置和它的截断逻辑一起删了，列表、搜索和统计现在描述同一组项目。

## 兼容性

旧 profile 里的 `ui.maxProjects` 会被忽略，不会报错；设置卡不再显示这一项。`/state` 的 `projectsTruncated` 字段已移除。
