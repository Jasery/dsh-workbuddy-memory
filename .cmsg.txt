fix(ui): 配置卡补上注入上限与蒸馏阈值的控件

上一版加了 inject.limits.user=8000、inject.distillAbove 的 schema 和文案，
却没有在配置卡里加对应控件 —— 面板上根本看不到，只能手改 cordis.patch.yml
才碰得到。schema 里可配不等于界面上可配。

- 配置卡「注入与写入」组补三个 NumberField：用户记忆上限、蒸馏阈值、
  项目记忆上限，均带说明与 0 的语义（0 = 不注入该块 / 0 = 上限的两倍）
- 蒸馏阈值显示的是**生效值**：存的是 0 这个哨兵（表示「跟随上限」），
  直接渲染 0 会被读成「蒸馏关着」，实际它正以两倍上限运行。显式值照原样显示
- 补 settings.projectLimit 的中英文案

测试 196 → 199。新增两条：卡上确实渲染出这三个标签与当前值；存 0 时
显示 16000（5000 上限则显示 10000），显式值不被推导覆盖。原有那条只断言
「输入框数量 >= 7」，所以漏掉了这个问题。

真机验证（dsh --profile web + Chrome）：配置卡显示
用户记忆上限 8000 / 蒸馏阈值 16000 / 项目记忆上限 10000。
